# 限定场景手语数据集目录

## 目录用途

- `raw/P001/`：参与者 P001 的原始视频，按标签目录存放。
- `processed/clips/`：从连续录像切出的派生片段，不能覆盖原始视频。
- `processed/keypoints/`：MediaPipe 等工具提取的关键点序列。
- `splits/`：按人员划分的训练、验证和测试名单。
- `consent/`：参与者授权材料，禁止随训练集对外分发。
- `rejected/`：质检不合格的视频。
- `references/`：动作标准参考、审核记录和版本说明。
- `exports/`：导出给训练程序的数据清单。

## 文件命名

`参与者编号_标签编码_序号_速度.mp4`

示例：`P001_SL01_001_normal.mp4`

速度使用 `normal`、`fast`、`slow`。不要在文件名中写真实姓名。

## 增加参与者

复制 `raw/P001` 为 `raw/P002`、`raw/P003` 等，并保留内部21个类别目录。

## 强制规则

1. 原始视频只读保存，不在原文件上裁剪或转码。
2. 动作未经专业人员确认时，`review_status` 不得写成 `approved`。
3. 训练、验证、测试必须按 `person_id` 隔离。
4. `UNKNOWN` 是正式类别，必须覆盖日常动作、不完整动作及其他手语。
5. 删除参与者数据时，同时核查原始视频、派生片段、关键点和元数据记录。
