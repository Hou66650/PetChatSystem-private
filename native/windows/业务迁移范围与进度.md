# 派特岛完整业务迁移

用户在 2026-10-18 确认：账号、语音、种植等现有业务全部迁移。雪境岛、山岭岛沿用已经完成的精细模型，只有 UE 导入、材质、光影、性能和交互适配，不重新设计。此清单是剩余工作的范围，不能将当前批次视作全量交付。

## 当前可运行链路

- 客户端 `I` 打开原生账号面板；注册、已有账号登录、余额、补给购买、每日补给、花园开启/买种子/播种/浇水/施肥/收获、文本聊天和历史读取已经接入服务端。
- 账号令牌只留在进程内；服务端只存摘要，支持撤销和过期。原生接口不读取或生成浏览器登录 Cookie。
- 经济/种植操作先保存本地回执，再发请求。网络结果不明确时保留回执，通过相同 token 重试；回执按服务地址和账号隔离，退出后不自动重放，不含密码或登录令牌。
- 猫岛按账号的品种、阶段、床位和已保存摆放位置加载植物。复用 140 个阶段模型和花盆，异步加载；登录时隐藏离线美术母版的示范作物，避免与账号植物叠加。点击种植床打开对应面板，`J` 聚焦花园。
- 专属声音提供本机直接录音、试听、授权确认、上传创建、创建状态刷新、音色选择和试听；聊天回复可使用当前音色朗读。切换宠物/账号、关闭面板时停止声音并隔离过期返回。
- 四张岛屿地图可用 `1/2/3/4` 切换。雪境岛和山岭岛的原始精细模型分四个模块导入，分别配套哈士奇/德牧现有骨骼与 35 段动画。

## 启动与数据

入口：`打开派特岛客户端.cmd`，启动 127.0.0.1:5012 的客户端业务服务，然后打开 ShippingDaily。5002 网页服务不重启；5003/5004 已被其他服务占用，因此不抢占。

业务服务读取 `D:/PetChatSystem/app/config.py` 的配置，直接使用原账号数据库，不复制成另一份用户数据。首次启动会创建原生会话表；其他经济、植物、聊天、声音资料继续使用已有服务和所属账号。没有自动登录、自动购买或自动调用模型。

隔离检查使用 `Start-NativeService.ps1 -Port 5013 -Fixture` 和 `Test-NativeBusiness.ps1 -Capture`；专用 SQLite 位于 Saved/Qualification，测试账号不能视为正式用户。正式服务与测试服务不可混用。
