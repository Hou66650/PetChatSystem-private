# Windows 客户端开发约定

- 此目录只在 codex/windows-client 分支开发；原网页目录是 D:/PetChatSystem。
- P0/P1 只允许隔离演示，不调用生产经济、种植、传送写接口。
- Unreal Engine 5.8 为待资格验证候选。toolchain-lock.json 只有实际编译、Cook、运行验证后才能标记 qualified。
- 未编译的 C++、未运行的画面及未采样的 FPS 必须明确标记未验证。
- 模型加工使用 Blender；高精母版在原仓库 art 目录保留，客户端运行资产另外生成。
- 不提交私模、密钥、用户数据库、DerivedDataCache、Saved、Intermediate 或 Binaries。
