# 双传送门

## 使用

在小岛底部「动作 → 双传送门」打开控制面板，也可以直接点击门。猫咪会自主选择门口探索，其他原生宠物会在空闲时好奇靠近。门只表达出发意愿，永远由主人点击「确认出发」。拒绝后宠物离开门口。

现实门：双击项目根目录 `Start-Desktop.cmd`，先在网页确认出发，把网页提供的两分钟一次性配对码粘贴到桌面客户端。客户端默认连接 `http://127.0.0.1:5002`；公网服务必须使用 HTTPS。首次换电脑需要在 `desktop` 目录运行 `npm ci`。客户端显示原始 GLB 动画模型，右键宠物可以摸摸、返回或打开控制台；网页右下角也有召回入口。两端不能分别复制一只继续活动的宠物。

软件感知按行程单独开启，默认关闭。Windows 感知只读取前台应用类别，以及可访问的控件边界，不上传窗口标题、文档正文、文件名或截图。文档类应用识别 WinWord/Excel/PowerPoint/记事本/WPS/VS Code；视频类支持 VLC/PotPlayer/系统播放器。如果播放器公开带进度语义的可访问滑块，会靠近该滑块，否则只停在桌面侧边。浏览器网页播放器的播放状态和进度条不在本版识别范围。桌面激活且可访问性提供图标边界时，宠物可走近图标；记录是“拜访图标”，不是读取或操作文件。

友邻门：双方登录各自账号，交换好友邀请码。岛主在对应宠物页面开启「允许好友宠物进入当前岛屿」，访客选择该岛屿后确认。确认后访客打开互动现场链接，持续运行串门模拟；好友在自己对应宠物的小岛页面会自动看到来访者，无需另开现场页面。位置和动作随行程状态同步。双方仍可从面板打开同一场景旁观和留言。切换到其他宠物岛时移除访客模型，切回后按最新行程恢复；召回或权限关闭后清理。每座岛同时接待一只访客；主人召回或岛主结束接待、关闭权限都会结束行程。两只宠物分别运行导航和行为状态，模型只提供受约束的下一步意图，模型忙时保持本地行为。

`/journeys` 展示真实上报轨迹、行为摘要和纪念品，从探索观测台可进入。桌面轨迹使用屏幕归一化坐标；串门使用岛屿米制坐标，图上分别自动缩放。持续上报最多保留最近 2400 条事件，留言最多展示最近 30 条。叙事是事件摘要，不虚构没有观测到的行为。

## 生命周期与性能

- 数据库对 `(owner, pet)` 的进行中行程设唯一约束，多个页面不能同时发起两种传送。
- 桌面配对码单次使用、两分钟失效；配对凭证仅在桌面主进程内存中使用，行程结束即撤销。
- 活跃行程 45 秒未收到实际运行端心跳则自动返回；串门十分钟、桌面三十分钟后视为精力不足返回。关闭串门运行页会结束模拟，双方观测页不会伪造运行心跳。
- 串门仅请求目标场景与两个模型；桌面仅请求当前宠物。桌面渲染约 30 FPS，DPR 上限 1.5，控制台与渲染进程隔离。粒子和门只属于当前选中场景。
- 当前浏览器帧率与后台节流仍会影响串门模拟；后台长期暂停时按断线规则返程。

## 扩展边界

四种原生宠物均可出发。`portal_custom_pets` 和服务端 `register_custom_pet` 为未来照片转 3D 管线提供统一资产接口；必须由该管线验证 GLB、骨骼、动画、体积和资产归属后注册。照片上传/云端生成不在本次新增范围，自建纪念岛默认禁止访客，主人可显式开启。

皮肤和礼物能力仅预留为外观扩展，当前没有计费、支付或影响能力的付费逻辑。现有门造型和纪念品为免费基础版本。

## 验证

`python -m unittest discover -s test -p test_portals.py` 覆盖授权、确认、互斥、配对重放、凭证撤销、访客关闭、自建纪念岛默认值、归属、轨迹校验和奖励幂等。

`desktop/node_modules/electron/dist/electron.exe test/desktop-render.cjs` 使用独立测试窗口验证真实 Three.js / GLB / 骨骼动画渲染，不读取或控制已有浏览器会话。

桌面安全边界遵循 Electron 的上下文隔离、沙箱与 IPC 来源校验文档：
https://www.electronjs.org/docs/latest/tutorial/security/
