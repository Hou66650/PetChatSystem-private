# 宠物专属说话声音

实时语音上下文（v1.57.3）：语音使用精简档案与场景事实，基础 instructions 上限 4400 UTF-8 字节，保留角色、语气和行为边界；不包含寻路坐标、approaches 或完整植物数组。这是保守的文本预算，不声称等于供应商 tokenizer 的精确计数。自主探索仍读取完整世界快照。

持续通话在已完成六轮、累计对话文本达到 2400 UTF-8 字节、或服务端报告输入达到 5500 token 时，等待回复播放结束和当前发言结束后换新 WebSocket。只带最近两轮各字段最多 240 字节的摘录，不重放音频；历史聊天和长期记忆不删除。声纹模式原本按轮创建独立连接，不跨说话人携带摘录。换连接核对账号、记忆版本和声纹设置，15 秒超时结束并提示。协议依据：[智谱官方 Realtime 文档](https://github.com/MetaGLM/glm-realtime-sdk/blob/main/GLM-Realtime-doc-for-llm.md) 的连接内历史机制。

入口：小窝或聊天页 → 选中宠物 → 资料 → **专属声音 · 上传录音**。

1. 登录账号，选择 3–30 秒单人说话录音，推荐 10–20 秒，无背景音乐。支持浏览器可解码的 WAV、MP3、M4A（原文件最多 20MB）。
2. 本地试听原音；填写声音名称，可补充与录音一致的原文。确认录音为本人或已获授权用于复刻，点击创建。
3. 页面异步显示创建状态和玻璃加载提示，可以关闭后再回来查看；创建成功不会自动启用。
4. 点击「试听新声音」，满意后「应用给当前宠物」。后续新文本朗读及重新开启的语音通话使用该音色。
5. 可以恢复默认；其他宠物和其他账号不受影响。删除时请求清理云端音色及样本，失败会保留记录供重试。

这不是熟悉声音识别，也不替换汪汪、喵喵等动物叫声。四种原生宠物（以及复用其槽位的上传外观）都可以独立设置。

## 服务链路

- 复用服务端 GLM_API_KEY / GLM_BASE_URL，不向浏览器暴露凭证或供应商音色 ID。
- 浏览器先解码并转为单声道 24kHz PCM WAV；服务端再次检查真实 WAV 格式、帧数、3–30 秒时长、音量与 2MB 上限。原始音频只在本机内存中处理，然后发送至智谱创建音色；不会写入静态目录或数据库。
- `/files`（purpose=voice-clone-input）→ `/voice/clone`（glm-tts-clone）→ `/audio/speech`（glm-tts）。上传、复刻和试听会使用供应商服务，可能计费。
- 记录存于账号隔离的 pet_voice_profiles / pet_voice_selection；前端提交的 voice 字段不会影响合成。语音通话带已绑定的 profile ID 和账号 scope，设置变化或账号切换会拒绝旧请求。
- 创建使用幂等提交 ID，不自动重试可能计费的上游创建；全进程同时最多 2 个创建任务，每账号最多 12 条记录。中断超过 5 分钟标记结果待核查；核查通过云端列表的精确服务端名称找回结果，不重复创建。
- 智谱 Realtime 公开文档仅列出预设 voice，tts_source 固定 e2e，不能据此承诺兼容 GLM-TTS 克隆 ID。专属模式保留原理解/回复链路，忽略其默认语音输出，将完成的回复文字交给 GLM-TTS 朗读，因此可能增加首音延迟及合成成本。未设置专属声音时原实时流式链路不变。
- 插话、挂断、切宠和连接关闭均取消待生成语音；解码完成后的回调仍核对当前轮次，避免旧音频复活。合成失败有明确提示，不悄悄改用别人的声音。

## 验证与限制

`test/test_pet_voice.py`：隔离数据库覆盖创建/试听/应用/恢复/删除、跨账号和宠物隔离、无效录音、幂等、超时核查、删除失败保留、同账号新浏览器持久性。

`test/pet_voice_realtime.cjs`：默认语音抑制、当前音色请求、重复事件、插话/挂断/迟到解码、错误与说话状态；现有 realtime_regression、realtime_playback_regression、realtime_error_regression 均回归。

`test/pet_voice_browser.py`：真实 Chrome 对隔离服务测试实际音频解码上传、原音/新音播放器、应用、切宠、重新打开、移动端布局、恢复及删除；供应商用替身，不产生真实复刻费用。2026-10-16 对现有账号只读调用官方音色列表得到 200 和有效 voice_list。尚未用用户真实录音做付费克隆或主观音色相似度验收；需要用户上传后验证。
