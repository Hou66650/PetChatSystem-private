# 派特补给站

入口：首页、小岛「更多」、猫咪外观市场。地址 `/supplies`。

## 本期范围

实现规划的第一阶段：商品货架、购买确认、账号库存、共用代币、免费口粮和清水，
以及购买/领取 → 送给某只宠物 → 进入对应小岛使用的完整流程。
货架为响应式插画界面，页面不加载任何宠物 GLB。

商品：日常口粮 10、精致餐盒 25、零食 8；星光弹力球 60、云朵毛绒骨头 80。
后两者为原有球/毛绒骨头的新增配色款，复用现有抛接和手势操作，永久拥有。
原有七种玩具保留免费；每个账号每天可领 3 份口粮，按北京时间自然日计算。
清水免费不限次，一只宠物同时只处理一份补给。外观市场每日代币共用，不能重复领取。

新配色只克隆选中玩具的材质，归还后再次选择原款会恢复；场景释放时销毁克隆材质。
食物、水使用期间按需创建低面数陶瓷碗，走安全路线后停下使用，完成后释放。
本期饮水复用低头进食动作；猫咪食物改变其已有饥饿状态，清水不改变饥饿值。
没有新增离线饥渴惩罚。猫咪观测事件会记录实际完成的补给，不冒充模型决策。

后续阶段仍待实现：自动饮水机、逗猫棒等新用品及专属动画、持续摆放的生活设施，
以及可旋转的完整 3D 超市场景。本期货架不销售这些尚不可用的商品。

## 持久化与恢复

- 与 `cat_wallets`、`cat_coin_ledger` 共用钱包，库存独立存储。
- 价格只由服务端决定；购买在同一 SQLite 写事务内扣币、入库、写账本。
- 操作编号按账号去重，重试相同购买不会重复扣币；编号不可用于不同参数。
- 食物送出时扣除一份库存，写入持久待使用记录；取消未开始的补给会退回一份。
- 玩具使用不扣库存，清水不扣币。访客可浏览，购买及使用需登录。
- 小岛领取补给时使用 90 秒租约，其他标签不能同时领取。租约过期可恢复。
- 完成后的重复确认不重复消费。网络重试仍可能在关闭页面后重播动作，但不会再次扣库存。
- 宠物旅行期间不能发送/领取新补给；切换宠物、离开页面或互动打断会延后使用。
- 同源和账号 scope 校验，不接收客户端指定 owner。

## 岛上的实体食盆、水盆（v1.38.0）

猫咪岛猫窝旁的两个盆支持鼠标悬停查看盆内百分比、点击或轻触打开补充面板，并可邀请猫咪吃饭/喝水。首次赠送满盆，账号持久保存，独立于背包库存。每次完成吃饭/喝水扣 25%，中途打断不扣；空食盆不再被 Agent 选择。补充一份基础口粮增加 25%（封顶 100%），清水免费加满；满盆不扣库存。百分比是游戏容量，不是现实克数或毫升。

补给站原有“使用食物”仍为直接喂食，不计入固定食盆；固定食盆请直接点击补充。实体交互目前绑定猫咪岛已建模的喂食架，其他岛不生成看不见的交互点。游客可以预览，登录后才保存与补充。

`node test/island_bowls.cjs` 验证真实 GLB 的射线选取及空盆隐藏内容物。
