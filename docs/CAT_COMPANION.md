# 猫咪陪伴体验与自主行为 v1.39.0

本轮覆盖批准的四阶段：稳定核心动作、关系驱动行为、每日故事、场景优先入口。复用原有猫咪模型与动作，不以提高模型请求频率代替自主能力。

## 一只猫的执行方式

当前原生猫咪 pet=3 按账号拥有相处记忆和稳定性格，换外观不换身份。浏览器中控制身体的 Agent 根据饥饿、口渴、精力、可达地点、访问记忆、性格和相处偏好选择行为。模型在后台提供白名单建议，新的建议只在下一次选择目标时评估；没有模型或响应慢也能继续生活。

用户明确操作优先于行为链与自由探索。寻路八秒没有实际进展时终止目标并冷却；吃完后视口渴程度去喝水，再回安静处整理毛发。走动、跳跃、墙面互动继续使用安全导航。传送仍需玩家确认，不能由模型自行授权。

同源同账号、支持 Web Locks 的浏览器只保留一个自主执行页面；隐藏或离开猫咪场景后释放。此锁不跨浏览器、跨电脑；服务端补给幂等与账号隔离仍保留。后台页面不模拟离线生活。恢复本机已保存且仍可行走的位置，以闲置状态继续，需求不按离线时长恶化。

## 关系如何影响行为

服务器只保存有限的事件类型、目标 ID、时间、编号；不存聊天、录音或模型内部推理。每账号最多保留最近 2000 条记录。重复编号去重，重复抚摸/玩耍有计数间隔。需要不同日期的真实互动，单次长时间挂机不会达到熟悉状态；自主吃喝不计入主人照料。

熟悉后会主动走近，熟悉程度影响停留距离；每次邀请间隔至少两分钟。有已玩过且放在可达地面的寻回玩具时，可以叼到视角附近邀请，不从关闭的柜子隔空取玩具。没有回应不扣关系。记录三个不同日期的同一三小时时段访问后，进入该时段时可先去入口附近看看。日期与时段统计使用北京时间，浏览器时区应一致。

性格中的好奇、社交倾向由账号稳定生成；本地选择使用好奇心和社交倾向，模型收到性格与偏好摘要。它们是有边界的游戏行为参数，不表示真实意识或无限制工具执行。

## 入口和每日体验

猫咪界面上方可打开「可互动位置」与「今天的小故事」。猫窝、植物、传送门支持场景悬停与点击，食盆、水盆沿用真实模型射线选取。三步引导为认识、玩耍、照料，允许跳过与重看。重复的动作/喂食导航收起，更多中的「动作与照料」保留备用操作。

每日故事只概括当日已经记录的事件，分享卡片先预览再保存。观测台也展示故事与相处印记。记忆可主动清除，不影响库存、外观或聊天。已完成但未同步的事件按账号暂存本机，网络恢复/重新打开后使用原编号重试；暂存最多 32 条，不保证无限期离线保存。

现有植物次日生长、声纹、语音指令、自动画质功能复用并回归验证。语音识别仍需要当前服务端/供应商，未增加离线 ASR；自动化验证不等同于本机真实麦克风验收。没有修改 Windows 显卡偏好，也不能由网页强制选择独显。

## 决策证据（v1.57.0）

探索观测台增加「一次行动是怎样发生的」：环境注意事项、选择时的需求快照、实际选中的目标与来源、后台建议状态、执行结果和完成次数变化。展开后查看本地评分前八名、最多八条排除原因，以及最近八次行动结果。排序分数是规则计算值，不是模型概率；模型建议刚返回、下一轮采用和当前正在执行分别记录，不推测模型内部推理。

行动被打断或受阻不会增加完成次数；完成上报区分本机计数和服务器确认。该记录来自猫咪页面的运行遥测，用于诊断，并非服务器独立验证的行为。沿用每两秒遥测和账号隔离，不额外请求模型；关闭或切到后台的小岛仍会暂停探索，观察时建议将小岛与观测台分为两个可见窗口。旧页面没有详细记录时提示刷新，服务端兼容旧遥测。

后台决策输入补入口渴值，口渴较高且有可用水时优先饮水。移栽植物不再只取最后十六株，当前账号全部已摆放植物都参与可达性筛选；界面排名仅展示前八名，不截断实际候选。

新增验证：`cat_decision_trace.cjs`（异步建议、真实选择、评分与结果）、`cat_decision_browser.py`（隔离账号的真实 Chrome 小岛→后台遥测→观测台）、`cat_scene_monitor_render.cjs`（窄屏、账号/实例切换及文本注入）。
