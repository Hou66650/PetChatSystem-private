# 熟悉的声音（实验功能）

小窝「更多 → 熟悉的声音」或语音面板「熟悉的声音」打开设置。填入称呼，点击录入，在安静环境自然说话14秒；至少需要6秒有效人声。仅录入本人或已同意的熟人。最多5位，支持删除、关闭。设置在下一次通话生效。

声纹由应用后端本地提取，数据库仅保存姓名和三段256维特征，不保存原始录音。数据随登录账户隔离，游客随浏览器会话隔离。日常语音仍使用现有云端语音服务；声纹特征不发给语音服务，只发送本轮亲近程度和匹配的称呼。

熟悉声音回应亲近；陌生声音回应简短、礼貌；短句、噪声、多人相似或分数不确定保持中性。“球球”两字通常不足以稳定识别，可用正常长度的一句话。不是身份认证，不能防录音冒充，阈值仍需真实家庭录音验证。

当前流程：本地停顿检测（700ms，单句最多15秒）→ 后端人声检测/声纹提取 → 新建语音会话并设置本轮提示 → 发送该句音频。辨认与连接阶段请等待面板提示，该阶段不接收新一句话；因此比普通通话有额外延迟。为隔离不同说话人的信息，本模式每句使用独立上下文，不读写个人陪伴记忆；关闭后恢复普通连续通话上下文和记忆。明确识别为陌生人时不派发小窝动作命令。

## 安装

在运行 Flask 的 Python 环境执行 `scripts/install_voiceprint.ps1 -Python <python.exe路径>`。依赖是可选的，不安装也能使用普通通话。Windows 使用 webrtcvad-wheels 提供 webrtcvad，避免编译器依赖；Resemblyzer 用 --no-deps 安装，安装脚本显式补齐依赖。

使用 [Resemblyzer](https://github.com/resemble-ai/Resemblyzer) 自带预训练编码器（Apache-2.0）。CPU按需加载，不占用小岛GPU。余弦相似度均值≥0.80且领先第二人≥0.08判熟悉，<0.58判陌生，中间区间不确定；这些是保守的初始工程参数，并非已验证的准确率。

自动测试覆盖账户隔离、删除、短录音、阈值/近似声音、同轮提示、取消竞态和旧语音回归。真实身份识别效果需本人录入后以本人和另一位同意测试的人交替说话验证；合成音频测试不能代替这一步。
