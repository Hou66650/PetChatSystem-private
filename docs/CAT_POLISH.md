# 猫咪观测卡片与动作打磨

观测台顶部「生成分享卡片」冻结当前选中实例的快照；预览后保存 PNG。
卡片的距离仅来自当前保留的连续轨迹段，不把断线、传送或清空前的点连接。
地点来自该实例保留的事件目标，代表记录中出现过，不代表全部完成。
不导出账号 ID、决策原因、录音、聊天；无实例时不可生成，有实例无轨迹时显示零。
时间是最后一次遥测时间，过期会标记最近一次记录。下载不自动发布到任何平台。

## 模型

`scripts/blender/polish_cat.py` 从不可变 v2 GLB 构建 v3：按实际面部坐标划分
眼表、鼻头、内耳粗糙度，添加 8 根渐细的弯曲眉须，绑定 head 骨骼。
仅增加 288 个三角形，保留表情形变、挂点及 35 个动画。v2 仍作为构建源保存。
`scripts/build_cat_coats.py` 基于 v3 重建四种市场外观；没有更改购买 ID 或猫咪身份。
`scripts/render-cat-coats.cjs` 更新实际模型封面。

## 行为

- 视线关注点停留 1.8–5.4 秒，再选择下一处；移动看路、用户指向优先级不变。
- 理毛 7.2 秒：坐姿、抬爪、小幅舔舐节奏、停顿、擦脸、收爪；左右随机。
- 蹭墙 5.4 秒：脸颊接触后肩部跟进，保持安全导航位置。
- 小跳保留原安全走廊和桥梁禁跳，增加蓄力、落地压缩。
- 短于 2 米的目标慢走；一般休息坐下、停留、起身，吊床保持睡姿。

这是在现有重建网格和共享骨架上的精修，尚不是完整的猫科肌肉模拟。
大角度抬爪容易牵扯肩部蒙皮，因此限制肩旋转，通过坐姿和肘部折叠表现理毛。
新增动作层每帧还原，用户指令和拾取交互可中断，不积累骨骼旋转。
