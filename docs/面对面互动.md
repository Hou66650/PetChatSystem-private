# 面对面互动（v1.11.0）

## 入口和玩法

在小窝的「更多 → 面对面互动」打开设置。可开启摄像头，也可以选择鼠标 / 触屏体验。

- 自由触摸：按住头顶、下巴或背部缓缓移动。连续移动会反馈亲昵动作，停留后会蹭手；亲密度奖励仍受原有每日限额约束。
- 梳毛刷：选择后在背部缓慢移动。前视角身体可能被头部遮挡，可旋转视角再梳背部。
- 抛接球：按住画布、拖向安全空地后松开；摄像头模式用捏合拿球、松开抛球。也可以点击「抛一个球」。宠物追球、叼回起点并放下。水面、障碍物和岛外落点被拒绝。
- 零食：从喂食菜单拖动零食，或用手势拿取。举到头顶会坐下等待，远一些会沿安全路径跟随，移至嘴边完成喂食。
- 自然注视：宠物跟随脸部位置和歪头，回应眨眼。这里使用面部方向与位置启发式，不是精确眼球视线定位。

脸部、手部、手势反应、镜像和提起均可单独调整，提起默认关闭。将手放在舒适位置后点击「以当前手的位置为中心」，可配合灵敏度调整控制范围。模式选项保存于当前浏览器。

## 实现和生命周期

FacePlay 负责触摸区域、骨骼姿态叠加和拾球状态；每帧先恢复上一帧基姿态，避免累积旋转。柴犬、哈士奇复用既有表情动画与嘴部挂点，并保留各自反馈文案。本次未新增 Blender 动画资源。

DenVision 优先使用 classic Worker + 动态模块导入，兼容 MediaPipe WASM 的 importScripts。一次只传输一帧，按设置仅创建脸部或手部模型。线程不可用时回退低频主线程推理。摄像头帧仅在本机处理。

退出、页面隐藏、切换宠物或外部交互会取消当前道具动作；停止摄像头会关闭流轨道、推理器和 Worker。异步初始化使用代次标记防止旧请求覆盖新会话。拾球采用既有导航路线，不新增跨水域行走能力。

## 验证

- `node test/faceplay_regression.cjs`：12 项自动测试，覆盖选项、运动触摸、校准、异步取消、选择性模型加载、Worker 背压与回退、骨骼恢复，以及真实 Three.js / Navigation / Locomotion 下的安全拾球。
- 既有柴犬/哈士奇表情、连续指令、选中才加载、河流和雪岛导航测试通过。
- `test/vision_worker.html` 是无摄像头人工验收页：临时复制到 static 下，通过本地服务打开，分别点击仅脸部、仅手部和两者；返回空地标结果代表真实 WASM 推理执行成功。结束后删除 static 中的临时副本。它不验证真人识别准确率。
- 浏览器检查了桌面与 390 × 844 视口、设置开关、指针触摸与拾球。真人摄像头的光照、遮挡、跟手体验仍需实机验收。


## v1.11.1 性能处理

页面通过 high-performance 请求高性能 GPU，但最终设备仍由浏览器与 Windows 决定。更多 → 流畅度可查看实际 WebGL renderer；GPU 识别后端表示 MediaPipe 使用图形加速，不等于必然使用 NVIDIA。

自动画质保留模型，最高 DPR 1.5，总绘制像素上限 240 万；阴影为 1024 或 512，分别以 20 / 12 / 8 Hz 刷新。每 1.5 秒统计实际帧间隔，跳过启动窗口，持续慢帧才降档、连续稳定窗口才恢复，避免频繁变化。手动画面偏好保存于本地；流畅档使用较实的玻璃底色。页面隐藏跳过场景更新和绘制。

验收：render_budget.cjs 检查自动档位与恢复、手动偏好、4K 像素预算及阴影更新；faceplay_regression.cjs 增加 GPU 成功与失败回退用例。真实浏览器 Worker 在空白测试画面上返回 GPU 与空地标结果。原有选中才加载、表达动画、连续指令、河流和雪岛导航保持通过。拍照保留 render → toDataURL 同步顺序；内置浏览器下载事件未返回文件，因此未据此宣称下载文件已验收。

本机 NVIDIA-SMI 检测到 RTX 5060 Laptop 8GB；内置浏览器检测为 Intel UHD。Windows 当前用户 Chrome 的图形偏好已由未指定设为高性能（GpuPreference=2），没有修改全局 GPU 设置。用户重启 Chrome 后报告 renderer 为 RTX 5060，面板为 240 FPS / 细腻 / 1.28×。这是该机器当次用户验收结果，不是跨机器性能保证；没有同条件优化前基准，不计算提升倍数。撤销本机偏好可在 Windows 的图形设置中将 Chrome 改回系统默认。

MediaPipe GPU delegate 选项参考：[官方 Web 配置](https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/tasks/web/core/task_runner_options.d.ts)。
