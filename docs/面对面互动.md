# 面对面互动（v1.11.0）

## 入口和玩法

在小窝的「更多 → 面对面互动」打开设置。可开启摄像头，也可以选择鼠标 / 触屏体验。

- 自由触摸：按住头顶、下巴或背部缓缓移动。连续移动会反馈亲昵动作，停留后会蹭手；亲密度奖励仍受原有每日限额约束。
- 梳毛刷：选择后在背部缓慢移动。前视角身体可能被头部遮挡，可旋转视角再梳背部。
- 抛接球：按住画布、拖向安全空地后松开；摄像头模式用捏合拿球、松开抛球。也可以点击「抛一个球」。宠物追球、叼回起点并放下。水面、障碍物和岛外落点被拒绝。
- 零食：从喂食菜单拖动零食，或用手势拿取。举到头顶会坐下等待，远一些会沿安全路径跟随，移至嘴边完成喂食。
- 自然注视：宠物跟随脸部位置和歪头，回应眨眼。这里使用面部方向与位置启发式，不是精确眼球视线定位。

脸部、手部、手势反应、镜像和提起均可单独调整，提起默认关闭。将手放在舒适位置后点击「以当前手的位置为中心」，可配合灵敏度调整控制范围。模式选项保存于当前浏览器。

## 实现和生命周期

FacePlay 负责触摸区域、骨骼姿态叠加和拾球状态；每帧先恢复上一帧基姿态，避免累积旋转。柴犬、哈士奇复用既有表情动画与嘴部挂点，并保留各自反馈文案。本次未新增 Blender 动画资源。

DenVision 优先使用 classic Worker + 动态模块导入，兼容 MediaPipe WASM 的 importScripts。一次只传输一帧，按设置仅创建脸部或手部模型。线程不可用时回退低频主线程推理。摄像头帧仅在本机处理。

退出、页面隐藏、切换宠物或外部交互会取消当前道具动作；停止摄像头会关闭流轨道、推理器和 Worker。异步初始化使用代次标记防止旧请求覆盖新会话。拾球采用既有导航路线，不新增跨水域行走能力。

## 验证

- `node test/faceplay_regression.cjs`：10 项自动测试，覆盖选项、运动触摸、校准、异步取消、选择性模型加载、Worker 背压与回退、骨骼恢复，以及真实 Three.js / Navigation / Locomotion 下的安全拾球。
- 既有柴犬/哈士奇表情、连续指令、选中才加载、河流和雪岛导航测试通过。
- `test/vision_worker.html` 是无摄像头人工验收页：临时复制到 static 下，通过本地服务打开，分别点击仅脸部、仅手部和两者；返回空地标结果代表真实 WASM 推理执行成功。结束后删除 static 中的临时副本。它不验证真人识别准确率。
- 浏览器检查了桌面与 390 × 844 视口、设置开关、指针触摸与拾球。真人摄像头的光照、遮挡、跟手体验仍需实机验收。
