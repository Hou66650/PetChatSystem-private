# 猫咪外观市场

首页「猫咪外观市场」进入 `/cat-market`，首页同时提供「猫咪探索观测台」直达 `/cat-agent-monitor`。小岛「一起动一动」的猫咪区域也有两个入口。

外观保留猫咪编号 3、昵称、记忆、亲密度和 Agent 状态。基础狸花免费；暖阳橘猫 120、云朵奶牛 180、秋日三花 220、月光布偶 300。月光布偶为共用骨骼的布偶风格外观，调整重点色、眼部颜色与颊毛/身体毛发轮廓，不代表独立品种骨骼。五款共用 35 组动画。

登录账号拥有独立钱包和永久外观所有权。初始 160 枚，每日手动领取 30 枚，前 5 次成功探索各 5 枚，前 3 次有互动的返程各 10 枚；北京时间自然日重置。探索奖励来自客户端成功事件报告，服务端去重和按日限额；这是无充值、无转赠、不可提现的游戏奖励系统，不适合直接接入现金经济。购买价格来自服务端目录，事务防重复扣币、并发透支，购买和启用分开确认。

小岛通过账号外观记录加载模型；已打开的小岛收到同源外观变更通知或回到前台时更新，当前猫咪页面也每 15 秒检查一次。桌宠和串门从服务端领取同一模型路径。旅途中或接待猫咪访客期间不允许换装，避免两端外观不一致。账号未登录可以浏览和预览，但不能购买、领取或启用付费外观。

市场仅加载当前选中 GLB，其他卡片使用真实模型封面；切换预览取消旧请求并释放资源。构建脚本 `scripts/build_cat_coats.py` 从现有 GLB 派生颜色/毛发形态，保留关节、权重、形态键与动画，移除无用原贴图数据。`scripts/render-cat-coats.cjs` 在独立 Electron 文件窗口验证骨骼、所有动画数值并生成封面。

验证命令：
- `python -m unittest discover -s test -p test_cat_market.py`
- `python scripts/prepare_cat_market_fixture.py`
- `desktop/node_modules/electron/dist/electron.exe test/cat_market_render.cjs`

UI 测试使用本地隔离页面、模拟钱包响应及真实模型，不接触已有浏览器会话或用户钱包。
