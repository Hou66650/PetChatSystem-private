# 公共乐园自主游玩

主人选择伙伴并入园后，默认开启自主游玩，不需要逐个点活动按钮。页面显示伙伴当前意图；“我也想陪它玩”保留手动动作，操作后暂时优先响应主人，再恢复自主活动。“自主游玩”开关可以持续暂停或恢复。离开页面、断线、退出和模型未加载时不会继续派发活动。

## 行为决策

`static/js/park-agent.js` 是运行在主人客户端的效用评分 Agent，每秒最多检查四次，不请求大模型。它感知真实在园伙伴、可达草坪、当前活动和近期到访地点，使用本次游玩的精力、探索欲、玩耍欲、社交欲以及成长档案的性格选择计划。精力低时优先休息，重复活动受冷却抑制；没有同伴时自主探索、追球和休息，不生成假在线伙伴。

- 探索：走向较少访问的草坪 → 嗅闻 → 观察。
- 玩球：俯身邀玩 → 跑向场景中的球 → 嗅闻 → 开心回应。球保持场景坐标，不再绑定宠物身体一起移动。
- 社交：保留接近距离 → 朝向伙伴打招呼 → 嗅闻 → 邀玩。只控制自己的宠物；对方远离、休息或离园时放弃或重新选择。
- 休息：走到相对远离其他伙伴的草坪 → 坐下 → 躺下休息 → 起身、伸懒腰。

寻路仍使用共享静态障碍布局；近距离有其他宠物时等待，持续拥堵后另选活动。该层是软避让，不是多人刚体物理碰撞。A* 在下达目的地时运行，不放进每帧循环。

## 动作与同步

`park-motion.js` 适配四种标准宠物及现有成长模型的已制作动画：`play_bow`、`tail_greeting`、`sniff`、`curious_listen`、`sit_down/sit_idle`、`lie_down/sleep_loop`、`stand_up`、`stretch` 和步行/小跑。入座、躺下、起身先播放一次过渡，再进入循环姿态；缺少某个动作时按语义降级。没有新增 GLB 骨骼动画资产。

服务端仅接收白名单动作、活动类型、自动状态和可通行范围内的球位置，通过已有账号令牌和位置/线段校验后广播。`park_presence.behavior` 为增量字段，旧客户端仍可提交无行为信息的同步包；活动结束由在线主人客户端明确更新，长时间休息不会在五秒后被强行显示为空闲。

v1.93.0 新增低桥和大猫耳隧道自主游玩，详见下节。跳圈、树屋攀爬、小隧道、离线托管和长期行为学习尚未实现。

## 验证

- `node test/park_agent.cjs`：十分钟虚拟时间决策、精力休息、无虚构社交、同伴离开、人工接管、路线和四种动画资产覆盖。
- `venv/Scripts/python.exe -X utf8 -m unittest discover -s test -p test_park.py -v`：同步权限、长期休息、行为白名单、玩具位置及既有公共乐园检查。
- 运行隔离的 `test/park_review_server.py` 后执行 `test/park_agent_browser.cjs`：双账号无需点动作自动移动、活动切换、暂停、手动招呼同步、恢复和离园。另运行 `park_runtime_browser.cjs`、`public_park_render.cjs` 复验缓存、点击导航和五岛入口。

## 设施游玩（v1.93.0）

保留精细 GLB，不改四座生活岛。Agent 会在体力足够、设施空闲时自主选择低桥或大猫耳隧道，走到入口后申请使用；没有按钮点击要求。

- 低桥：沿北侧坡道上桥、走过桥面再折返。远端靠近岛边，没有足够地面支撑，因此不安排从远端下桥。共享路线按实际板面约 0.556 米高度起伏，根节点随坡度俯仰，配合既有步行骨骼动画。
- 猫耳隧道：绕开桥身进入大洞，沿中线穿出另一端，转身后再返回草坪；宠物显示高度不超过 1.05 米才参与，德牧等较高体型自动跳过。小隧道保持观赏。
- 西侧入口通道共用，一次只容纳一只宠物进行设施活动；其他 Agent 去做别的事。入口附近有人时不选择，路线遇到其他宠物会停步等待。不是完整刚体物理系统。
- 暂停请求在返回草坪后生效，设施中临时禁用手动动作按钮；随时“结束游玩”仍能立即离园。后台、掉线和离园沿用公开存在清理；设施活动最长 120 秒，失联 12 秒释放占用。

`navigation.json` 保存经过模型射线验证的入口、出口、三维折线路径、限高和速度。普通草坪仍受原有边界与树坛校验，未扩大自由活动范围。设施路线以长度进度驱动；服务端在 SQLite 写事务内校验独占、体型、入口距离、单调进度、时间/速度和完成后退出，位置从共享路线计算，不信任客户端任意高度或越界坐标。其他用户按同一路线进度插值，桥面高度和转弯随之同步。

验证：`test/park_facilities.cjs` 用实际运行 GLB 射线检查脚下支撑、身体宽度/头顶空间、入口出口可达性及 Agent 体型/占用选择；`test/test_park.py` 验证独占竞争、伪造进度、提前离开、令牌、体型、失联和离园；`test/park_facilities_browser.cjs` 在两个隔离账号中验证自主使用两类设施、实际渲染高度、同步进度与安全暂停。截图保存在忽略目录 `uploads/harmony-dev/`，不提交测试账号或数据库。
