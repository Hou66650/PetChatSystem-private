# 真实回忆驱动宠物表现（首版）

## 使用流程

1. 登录后打开 `/pet-studio`（首页「把我的宠物带到岛上」），选择宠物档案，在「模样与动作」「照片、视频与记忆」之间切换。原 `/pet-imprint?petId=1` 入口会转到这里，下方折叠区保留已有的习惯和原声编辑。
2. 记录主人记得的习惯，或填写影像文件名、时间段及观察。选择活动、叫声频率、重逢、陪伴、玩耍、纯回忆等类型。保存后是草稿；勾选依据真实并接受表达方式，再确认启用。
3. 回到小窝，可点「我回来了」「陪我坐一会儿」「一起玩一会儿」。确认的活动习惯影响自主走动间隔和速度；明确设置的陪伴偏好优先。摸摸、手势、小游戏等已有事件也可排队触发对应习惯，忙碌超过 8 秒丢弃。
4. 在「管理它本来的叫声」上传视频或音频，本机 FFmpeg 提取音轨。试听、剪辑、确认并保存对应场景的原声，开启原声开关；再建一张对应原声回忆卡确认绑定。能量候选只帮助定位，不识别声音属于哪只动物。
5. 可随时撤回、删除、修改。修改后需要重新确认；同类新确认替代旧确认。暂停长期记忆会暂停这些记录；清空长期记忆删除回忆卡及新回忆素材库，原声素材库仍单独管理；建模参考照和模型不受影响。

## 汤圆演示

启动 `venv\Scripts\python.exe -X utf8 test/imprint_review_server.py`，访问 `http://127.0.0.1:5094/__qa/tangyuan`。端口可由 `PET_IMPRINT_PORT` 指定。

服务器仅监听本机，使用临时数据库及独立测试账号，不调用付费对话服务。可用环境变量 `PET_IMPRINT_REFERENCE` 指定真实视频路径（Windows 用分号分隔，最多两条）；本地提取后保留为待确认音轨，24 小时后不可继续使用。退出服务器即失去此演示数据库，下次启动重新建立。

已有主人描述「活泼好动」「不太爱叫」「喜欢在草坪上和主人玩耍」用于演示。前伏邀玩仅为待确认表达草稿，不能当作汤圆真实做过这一姿态的证据。测试中临时建立的坐下迎接样本会删除，不作为汤圆回忆保留。

当前用标准柴犬作为动作载体，展示回忆到行为的闭环。汤圆专属外形、视频逐帧步态和真实叫声仍须分别审核；本版没有自动从视频学习全部性格、动作捕捉、音色克隆或桌面动作联动。新建回忆素材按私人建模档案隔离，主人确认后显式应用到四个岛上伙伴槽位；不是任意数量的 custom-* 行为实例。旧手动影像参考表单仍只做本地预览，批量上传及视觉提取使用新的档案页入口。生产服务重启后才会注册新接口并建表；演示服务不代表已部署生产或鸿蒙设备。

## 同一档案的批量回忆素材（v1.103.0）

- 一次选择多份 JPG / PNG / WebP 照片或 MP4 / MOV / WebM 视频，逐份上传；重复字节合并，单项失败不回滚其他素材。照片不超过 8 MB，视频不超过 30 MB、120 秒；每档案 40 份，账号总共 300 MB。照片去除 EXIF；视频原文件私有保存，六张等距关键帧用于核对和分析。
- 上传不调用视觉服务，也不碰五个建模角度及模型。勾选说明后手动提取，照片或六帧拼图发往现有 GLM 视觉服务；单份一次请求、60 秒读取超时、不自动重试。失败和中断保留素材，用户可手动重试，可能再次计费。
- 每份最多三条客观观察草稿，校验 JSON、帧号与长度。视频只分析抽样帧，不识别音轨、不推断连续运动或长期性格。无可靠观察时允许零条，不能伪造成功。
- 主人对照原始照片／视频时间点、补充真实依据、选择往事或已有互动模板，并明确选择岛上伙伴后确认。确认调用已有 `pet_imprints` 行为链；同类习惯替代旧确认，旧记录保留。撤回、删除素材、删除档案会撤销该来源发布的记忆；暂停长期记忆时运行时不使用。
- 状态与素材只对当前账号开放。确认操作同时校验草稿版本与账号记忆版本；分析结束校验素材令牌和记忆版本，删除／清空后的迟到结果不能恢复数据。运行中的重复分析被拒绝，完成后重复提交直接返回已有结果。
- 旧案例属于原上传账号，不能从接口跨账号读取。维护工具 `scripts/copy_pet_studio_cases.py` 仅在明确获得档案复制授权后使用：先 dry run，`--apply` 要求独立数据库备份，复制后逐资产 SHA-256 验证，重复运行不复制第二份，不复制云端作业、启用指针、聊天或行为记忆。建模档案上限扩为 20，避免恢复案例后原有草稿占满五份限额。

## 行为与数据约束

- 服务端保存原始依据、表达方式、确认时间；上下文将真实往事与虚拟事件区分，不把回忆内容当指令。
- 每次动作重新读取已确认记录，模型缺少对应动作则提示待适配。自主触发冷却 90 秒；用户主动按钮可跳过冷却，但不抢占正在进行的互动。
- 手动操作、换宠物、页面隐藏及档案更新可取消该模块拥有的动作或原声；异步旧响应不能恢复播放。跨页面修改使用账号限定 BroadcastChannel，同页外的修改另有 15 秒轮询。
- 安静偏好关闭成长互动的通用动物音效，将自动原声间隔从 45 秒延至 180 秒；仍可主动试听，不更改聊天朗读设置。绑定原声按当前确认版本和启用状态读取，保持原始音高。
- 账号、宠物、版本和来源均校验。所有写操作要求登录、同源 JSON 和账号范围；API 私有且禁缓存。私人影像、音轨、数据库不进入 Git。

## 验证

`test/test_pet_imprint.py` 覆盖草稿、确认、替代、撤回、清空、跨账号／宠物、陈旧版本、原声授权与回忆上下文；`test/pet_imprint_runtime.cjs` 覆盖忙碌、过期、撤销、缺失动作与迟到响应。`test/pet_imprint_browser.cjs` 在上述隔离服务器验证表单确认、宽窄屏、真实 GLB 走近／坐下及撤回后的拒绝执行。不得把标准模型测试结果作为汤圆个体还原验收。

`test/test_studio_memories.py` 验证素材隔离、去重、确认／撤回、并发版本、删除与迟到分析、真实 FFmpeg 解码和视频 Range 读取、授权案例复制幂等。`test/studio_memories_browser.cjs` 验证统一入口、批量部分失败、草稿应用与移动布局；视觉结果使用明确的测试替身，不代表真实影像识别准确率已验收。
