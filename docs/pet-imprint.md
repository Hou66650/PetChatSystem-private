# 真实回忆驱动宠物表现（首版）

## 使用流程

1. 登录后打开 `/pet-imprint?petId=1`，或小窝「动作 → 熟悉的样子 → 记录或修改真实回忆」。当前按账号及四个伙伴槽位隔离。
2. 记录主人记得的习惯，或填写影像文件名、时间段及观察。选择活动、叫声频率、重逢、陪伴、玩耍、纯回忆等类型。保存后是草稿；勾选依据真实并接受表达方式，再确认启用。
3. 回到小窝，可点「我回来了」「陪我坐一会儿」「一起玩一会儿」。确认的活动习惯影响自主走动间隔和速度；明确设置的陪伴偏好优先。摸摸、手势、小游戏等已有事件也可排队触发对应习惯，忙碌超过 8 秒丢弃。
4. 在「管理它本来的叫声」上传视频或音频，本机 FFmpeg 提取音轨。试听、剪辑、确认并保存对应场景的原声，开启原声开关；再建一张对应原声回忆卡确认绑定。能量候选只帮助定位，不识别声音属于哪只动物。
5. 可随时撤回、删除、修改。修改后需要重新确认；同类新确认替代旧确认。暂停长期记忆会暂停这些记录；清空长期记忆删除回忆卡，原声素材库仍单独管理。

## 汤圆演示

启动 `venv\Scripts\python.exe -X utf8 test/imprint_review_server.py`，访问 `http://127.0.0.1:5094/__qa/tangyuan`。端口可由 `PET_IMPRINT_PORT` 指定。

服务器仅监听本机，使用临时数据库及独立测试账号，不调用付费对话服务。可用环境变量 `PET_IMPRINT_REFERENCE` 指定真实视频路径（Windows 用分号分隔，最多两条）；本地提取后保留为待确认音轨，24 小时后不可继续使用。退出服务器即失去此演示数据库，下次启动重新建立。

已有主人描述「活泼好动」「不太爱叫」「喜欢在草坪上和主人玩耍」用于演示。前伏邀玩仅为待确认表达草稿，不能当作汤圆真实做过这一姿态的证据。测试中临时建立的坐下迎接样本会删除，不作为汤圆回忆保留。

当前用标准柴犬作为动作载体，展示回忆到行为的闭环。汤圆专属外形、视频逐帧步态和真实叫声仍须分别审核；本版没有自动从视频学习全部性格、动作捕捉、音色克隆、私人 custom-* 独立档案或桌面动作联动。视频参考表单只做本地预览和出处记录，不上传视频，也不自动识别内容。生产服务重启后才会注册新接口并建表；演示服务不代表已部署生产或鸿蒙设备。

## 行为与数据约束

- 服务端保存原始依据、表达方式、确认时间；上下文将真实往事与虚拟事件区分，不把回忆内容当指令。
- 每次动作重新读取已确认记录，模型缺少对应动作则提示待适配。自主触发冷却 90 秒；用户主动按钮可跳过冷却，但不抢占正在进行的互动。
- 手动操作、换宠物、页面隐藏及档案更新可取消该模块拥有的动作或原声；异步旧响应不能恢复播放。跨页面修改使用账号限定 BroadcastChannel，同页外的修改另有 15 秒轮询。
- 安静偏好关闭成长互动的通用动物音效，将自动原声间隔从 45 秒延至 180 秒；仍可主动试听，不更改聊天朗读设置。绑定原声按当前确认版本和启用状态读取，保持原始音高。
- 账号、宠物、版本和来源均校验。所有写操作要求登录、同源 JSON 和账号范围；API 私有且禁缓存。私人影像、音轨、数据库不进入 Git。

## 验证

`test/test_pet_imprint.py` 覆盖草稿、确认、替代、撤回、清空、跨账号／宠物、陈旧版本、原声授权与回忆上下文；`test/pet_imprint_runtime.cjs` 覆盖忙碌、过期、撤销、缺失动作与迟到响应。`test/pet_imprint_browser.cjs` 在上述隔离服务器验证表单确认、宽窄屏、真实 GLB 走近／坐下及撤回后的拒绝执行。不得把标准模型测试结果作为汤圆个体还原验收。
