# 原生宠物行为

## 当前状态（客户端 0.11.0）

完整动作接入与验收边界见 [ACTION_PARITY.md](ACTION_PARITY.md)。原网页小窝保留 Web 绘制及全部既有互动，混合原生白名单目前关闭；独立原生入口扩展到 28 个动作。下文为 0.8.0 的历史实现和验证记录，其中原生启用状态及回环 HTTP 限制不代表当前版本。

## 网页小窝接入状态

0.8.0 已增加原网页 `/den` 的原生接入代码，不需要进入独立互动入口。网页继续负责原按钮、导航、碰撞、喂食、亲密度和账户事务；原生端接收原模型的完整世界变换、相机和动作参数，负责宠物绘制及动画播放，不启动另一套自主游走或写入独立入口的状态。

采用 ArkWeb 同层 `<embed>` 和透明 Component3D 纹理承载宠物，网页背景、花园及其余物品保持原渲染。原生完成确认前一直保留网页模型；会话或宠物变化使旧确认失效。非标准模型、配饰、抓取、面对面互动、玩球、持有玩具等仍用网页；景物遮挡采样命中时也回退网页，避免两个深度缓冲互不遮挡。混合渲染材质、阴影及遮挡边缘一致性尚需真机验收，不能视为逐像素一致。

**当前实际限制：** 2026-10-17 在 HarmonyOS 6.1 模拟器上取得运行错误：`the requested module '@ohos:graphics.scene' does not provide an export name 'Scene'`。这台模拟器未启动原生场景，“模型可见且能移动”是网页回退结果，不是原生渲染验收。能力探测放在模型下载前；失败后移除同层标签并停止额外同步，网页继续正常运行。进入现有“流畅度”面板可看当前渲染模式。真机基础接入已按下述记录验证；性能与完整视觉验收仍未完成。

原生通道只在已配置站点的 `/den` 主文档轮询；不向任意页面暴露文件、网络、账号或执行代码接口。模型路径固定为四个标准 GLB，消息最多 8 KiB；位置、缩放、四元数、相机、动画进度与速度均需通过校验。同步丢失 1 秒恢复网页模型。原生模块错误不会让网页消失。

可在模拟器验证网页回退、账号功能和业务规则。完整按钮遮挡、手势穿透、各宠物动画外观及 FPS 仍需在真机继续验证；“网页层 FPS”不能代替原生 FPS。

```powershell
node test/harmony_den_bridge.cjs
node test/harmony_den_node.cjs
```

以上执行实际桥接、协议和场景管理代码；SDK/GPU 边界使用替身测试，覆盖此模拟器暴露的模块缺失错误，不证明真实同层输出成功。

## MatePad Air 真机验证（2026-10-17）

- 使用本机 HarmonyOS 调试签名成功构建并安装客户端 0.8.0；签名材料及含密钥配置仅保留在本机，不提交仓库。
- 原网页小窝的标准猫咪通过原生确认：`ready: true`、`status: ready`，会话与当前模型 key 一致，渲染模式为“宠物：鸿蒙原生”。用户在该状态下确认模型、动作和旋转视角正常。这是猫咪基础接入的真机验证，不代表四只宠物、全部互动及生命周期均已验收。
- 同次读取的流畅度面板为“网页层 6 FPS · 细腻 · 清晰度 1.50×”。此为单次网页层读数，没有测得原生 FPS，也没有同场景前后对照；不能据此宣称整体性能提升。背景、花园及其余内容仍由网页绘制。
- 连接失败曾由电脑 Wi-Fi 地址变化造成，恢复原局域网后网页可达。当前验证使用配置站点的局域网地址；客户端现有地址策略不接受 HTTP 回环地址，不能直接把 USB 端口转发地址当作已支持的连接方案。

## 独立行为入口（0.7.0 起）

连接设置 → **原生宠物互动**。若启动直接进入网页，在网页首页按系统返回键进入连接设置。

本批把宠物行为状态机、坐标移动、朝向、语义动画选择、动作结束回调和本机恢复放到 ArkTS / ArkGraphics3D 中执行。网页入口及页面未改动；四只标准宠物使用与桌面相同的原始 GLB，不减面。原来的岛屿/动画对照入口继续保留。

## 已实现

- 团子、球球、雪球、德牧切换；加载完成自动待机，按模型原动画名称匹配动作。
- 散步/跑动在限定范围内往返，移动速度以实际时间计算，单步最多 50 ms，长帧不会突然跳远；只有移动时启动 33 ms 逻辑计时器。此计时器频率不是渲染 FPS。
- 呼唤会打断当前动作，走到前方、开心回应，然后回到待机。抚摸播放一次后回到待机；睡眠循环，唤醒播放起身动作再待机。
- 新命令打断旧动作；回调携带动作序号，过期回调和已销毁场景不会再启动动画。不支持的动作禁用或明确提示，不播放随机替代动画。
- 手动暂停与页面进入后台暂停动画、停止移动计时器；恢复时继续当前行为。退出或更换模型先停止行为，再释放场景和下载缓存。
- 按站点地址、宠物 ID 保存本机位置、朝向与睡眠状态。重新进入时恢复睡眠或安全待机，不继续执行未完成的呼唤、抚摸、跑动。损坏记录、错误宠物 ID、非法数值会被拒绝；位置越界会收敛到活动范围。

## 范围

独立行为入口仍保留，尚未替换完整岛屿场景。独立入口保存的是当前设备的展示状态，不是账号、钱包或宠物健康数据，也不与网页模式混用。聊天、补给、园艺等业务继续使用原网页和服务端；没有向隔离的移动端测试数据库写数据。

模拟器安装与编译通过不代表 GPU 画面或真机性能验收。尚无本版原生 FPS 对比结论。

## 验证

```powershell
node test/harmony_native_behavior.cjs
node test/harmony_native_preview.cjs
node test/harmony_client.cjs
node test/web_lan_compat.cjs
```

前两组执行实际 ArkTS 控制器/加载器源码，替换 SDK 边界进行状态机与生命周期测试，并读取四个实际 GLB 的动画清单校验动作映射；不以 mock 测试证明 GPU 渲染成功。使用 DevEco Studio 构建 HAP 后，在支持 ArkGraphics3D 的真机验证四只宠物的选择、散步、呼唤、抚摸、睡眠、后台暂停、重开恢复及旋转/缩放；当前模拟器只能验证网页回退。

动画结束回调语义参照[华为 ArkGraphics3D 动画管理文档](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V5/arkgraphics3d-animation-V5)，类型以已安装 SDK 的 SceneResources.d.ts 为准。
