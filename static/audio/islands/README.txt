Original instrumental music for PetChatSystem.
Generated deterministically by scripts/build_island_music.py from authored
melodies, chords, additive synthesis and circular stereo reflections.
No external recordings, samples or third-party compositions are used.
Each track is a 96-second, 24 kHz stereo FLAC loop.

sakura: Sakura Path / plucked pentatonic-inspired accompaniment
snow: Snow Starlight / soft bell arpeggios
camp: Mountain Evening / warm sustained strings
room: Mistwood Afternoon / gentle keyboard accompaniment

Playback is opt-in. Only the selected track loads; switching briefly retains
the previous track for a 1.5-second crossfade. Calls reduce music to 12% of
the selected volume. Hidden tabs stop and release audio, then restart the
current track when visible. Closing music releases all tracks.
