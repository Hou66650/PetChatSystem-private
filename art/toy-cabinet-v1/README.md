# 小岛玩具柜 · v1.12.0

## 设计与建模

- `design.png`：使用内置 imagegen 生成的设计板；完整提示词见 `design-prompt.txt`。
- `toy-cabinet.blend`：Blender 5.2 可编辑模型，`model.png` 为实际模型渲染。
- 重建命令：`blender --background --python scripts/blender/build_toy_cabinet.py`（项目根目录）。
- 木柜包含圆角顶板、背板条、六个开放格、编织篮、爪印装饰、黄铜挂钩；七种独立玩具为彩纹球、爪印飞盘、编织绳结、毛绒骨头、小黄鸭、木梳刷、小摇铃。
- 柴犬和哈士奇原布景中的球已拆成独立 `toy_id=ball` 节点，保留原来的几何和颜色；不重叠生成替代球。

## 操作

1. 直接按住岛上的球或柜格里的玩具拖动；也可从「更多 → 玩具柜」选择。
2. 曲线显示飞行轨迹，绿色圈是可达落点；红色代表河面、池塘、障碍或岛外，松手归还原位。
3. 「抛出」会让宠物寻回；「放下」只摆放道具，之后仍可拾取。梳刷和摇铃仅支持摆放及各自互动。
4. 木梳刷移过背部可梳毛，小摇铃晃动会吸引注意；「逗逗它 / 捏一捏」触发玩具回应，小鸭和摇铃使用短合成音效。
5. Esc 取消；「全部收好」恢复所有玩具。切宠物、隐藏页面和中止摄像头都会取消当前持物。
6. 摄像头手势沿用同一拾取、松手、失踪取消逻辑；本轮验证了模拟输入，未进行真人摄像头验收。

## 浏览器开销与验证

柜体及七个玩具共 8 个网格、21,696 个三角形，GLB 约 1.28 MB，无外部纹理请求；细节使用顶点颜色合批。仅请求选中岛屿和其柜体；切换时取消过期加载并释放资源。轨迹固定 33 个采样点，导航目标限频重算。

`test/toy_workshop.cjs` 覆盖模型标记和颜色、实际射线拾取、物件身份、取消归位、无效落点、再次拾取、预测/实际轨迹一致、寻回、梳刷摆放、手丢失取消和场景清理。另回归表情、语音动作、两岛导航、按需加载、瀑布、渲染预算和画面宽高比。浏览器实测涵盖雪岛飞盘寻回、原有球拾取及岛外拒绝。
