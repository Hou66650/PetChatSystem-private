# 哈士奇雪岛 v1.8.0

先用内置图像生成工具绘制 `design-board.png`，再按图用 Blender 5.2 建模。完整生成提示保存在 `prompts.txt`，昼夜背景原画为 `day.png`、`night.png`。模型没有把设计图当作平面贴片。

## 交付

- `snow-haven.blend`：可编辑 Blender 场景，网格按材质合批，构件仍保留独立网格岛。
- `courtyard.png`、`lodge-detail.png`、`ice-detail.png`：模型实渲。
- `../../scripts/blender/build_snow_haven.py`：可复现建模与渲染脚本；主要道具位置读取雪岛导航配置。
- `../../static/models/petchat-snow-v2/snow.glb`：网页用岛屿，138,876 三角面、16 网格批次、18 材质绘制单元，4,764,116 字节。哈士奇沿用已有带骨骼模型。
- `../../static/textures/snow-sky-v1/`：白天 84,590 字节、夜晚 112,532 字节的 WebP 背景。

木屋包含原木墙、拱门、阁楼窗、分块屋瓦、积雪屋顶、烟囱、木柴与年轮；外围布置积雪松树、雪人、雪橇、灯笼、冰池、食盆与球。中央保留活动区，屋檐、雪橇绳、池边石块计入避障。GLB 实测雪面高度 0.018，导航落脚高度 0.025。

## 加载策略

初始宠物由 `?pet=2` 或上次选择决定。仅下载选中宠物、选中岛屿及当前昼夜贴图；切换取消旧请求，清理旧模型的几何、材质、贴图和骨架。异步解析若晚于切换完成，也会释放结果。没有模型常驻缓存，不提前下载另一昼夜背景。浏览器自身 HTTP 缓存仍可复用已访问文件。选择按钮的小头像属于界面资源。

## 验证

`node test/selected_assets.cjs` 验证取消、迟到解析、去重释放、背景切换与无预加载。`node test/snow_navigation.cjs` 验证包括真实哈士奇体型在内的导航、冰池禁行和安全放下。`node test/snow_asset.cjs` 使用实际 GLB 几何验证绘制单元、文件预算、地面高度和哈士奇体型；该测试跳过贴图像素解码，由真实浏览器验收补充。

浏览器实际检查白天、夜晚、四宠切换、重新进入记住选择。直接进入哈士奇白天时，Flask 请求日志只有雪球 GLB、雪岛 GLB 和雪岛白天背景，没有其他宠物/岛屿 GLB、夜晚背景或音乐请求。原河流导航、瀑布材质动画、柴犬表情与口语动作回归通过。

演示：`http://127.0.0.1:5002/den?pet=2&scene=day`；将 `scene` 改为 `night` 查看夜晚。省略 `scene` 按本地时间切换。
