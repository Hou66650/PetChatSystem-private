# 球球表情与动作 v3

本轮仅升级柴犬球球。金棕毛色、白色里白、青色项圈与黄铜爪印吊牌沿用原有角色。

## 交付物

- `expression-design.png`：八种神情与四种动作的概念设计图。
- `motion-blueprint.png`：歪头、邀玩、挥爪、哈欠的关键帧与受力参考。
- `qiuqiu-v3.blend`：可编辑模型、33根骨骼、材质、动作及摄影棚。图像已打包。
- `../../static/models/petchat-v3/qiuqiu.glb`：网页实际使用的资产，保留20段旧动画并新增12段。
- `neutral.png` 及按动作命名的 PNG：实际 Blender 渲染，和概念图分开标示。
- `design-prompts.txt`：内置 image_gen 的最终提示词。
- `build-report.json`、`export-validation.json`：构建信息与重新导入 GLB 后的采样检查。

## 表演规格

| 动作 | 时长 | 关键变化 | 接地与过渡 |
|---|---:|---|---|
| curious_listen 歪头倾听 | 2.4 s | 约18度侧倾，单耳前转，眉部轻提 | 四脚接地，末段回中 |
| ear_perk 竖耳 | 1.6 s | 双耳竖起且轻微不对称 | 保持站姿 |
| shy_look 害羞 | 2.8 s | 收耳、低头、轻侧倾 | 不后退，不改变世界坐标 |
| alert_scan 观察 | 3.0 s | 耳向前、左右查看、眉部提起 | 四脚接地 |
| sleepy_yawn 哈欠 | 3.2 s | 慢闭眼、下颌打开、舌头微卷、抬头 | 起承转合，恢复中性 |
| affection 亲昵 | 2.6 s | 眯眼、脸颊提起、歪头、轻摇尾 | 不改变场景位置 |
| surprised 惊讶 | 1.6 s | 竖耳、抬眉、轻张口 | 无强烈跳跃 |
| play_bow 邀玩 | 2.8 s | 胸部下沉、后躯保留高度、摇尾 | 前脚小幅前伸，IK锁脚后烘焙 |
| paw_greeting 挥爪 | 2.4 s | 重心偏移、单前爪抬起、露出肉垫 | 另外三脚固定，抬爪复位 |
| nose_lick 舔鼻 | 1.8 s | 舌头上抬、轻歪头 | 四脚接地 |
| shake_off 抖毛 | 2.0 s | 头与躯干不同幅度摆动，耳部滞后 | 无根节点位移 |
| tail_greeting 欢迎 | 2.4 s | 尾根与尾尖错相、耳朵放松 | 留在原地 |

新增的 ear、brow、cheek、tongue、tail_tip 骨骼补足原有控制。眼球保持体积，通过眼睑形变、眼眶内收与贴合头部表面的闭眼弧线实现风格化眨眼。眼睑细节、鼻孔、耳内毛簇、胸毛、肉垫与短爪均为可编辑几何；未使用昂贵的毛发模拟。

## 网页接入

进入 `/den` 选择柴犬，点击“球球的小表情”。抚摸触发亲昵，停留时按陪伴偏好从合适的小动作中选择；安静模式避免活跃邀玩。动作执行仍受切宠、手动操作和对话取消控制。

`static/js/den/shiba-expression.js` 独立管理眼睑，不用全身动画打断行走。每帧从眼睛原始位置计算闭合，避免累积位移。生成的 GLB 也包含眼睑动画，供 Blender 和其他工具预览；小窝会提取面部通道交给独立控制层。

新自然语言动作只允许柴犬、小窝界面及本轮原文引用同时满足时执行。普通聊天页、其他宠物和任意动作名称均不能借此执行新动作。

## Blender 编辑与重建

在摄影棚打开 `qiuqiu-v3.blend`。骨架的 NLA 轨道按动作命名，默认静音；预览某动作时仅启用对应轨道。眼睑形态键数据上的同名轨道同步启用即可查看完整面部表演。当前动画无模拟缓存依赖。

重建：`blender --background --python scripts/blender/build_shiba_v3.py`。脚本仅清空其运行场景，因此请在独立 Blender 进程运行，不在未保存的个人工程中执行。

本轮使用用户指定的 [ahujasid Blender MCP 插件](https://github.com/ahujasid/mcp-for-blender)，会话内监听 `127.0.0.1:9876`。`scripts/blender/mcp_bootstrap.py` 加载本机 `uploads/blender-mcp/addon.py`；`bridge.py` 使用插件的 JSON 协议运行构建脚本。插件本体不打包进项目资产，构建也可直接使用 Blender Python。

## 验证范围

- Python 陪伴/语音回归与柴犬能力边界测试：使用临时数据库和模型替身，不调用真实 GLM。
- Node 回归：实时语音生命周期、表情选择、闭眼复位、取消后不执行后续动作、导出动画列表与页面脚本语法。
- Blender 重新导入最终 GLB：逐动作采样网格范围，检查非有限坐标、异常拉伸与穿地。
- 真实页面：模型加载、小表情入口、动作切换与其他宠物回退入口检查。

概念图是美术目标；PNG 渲染和网页模型是实际完成状态。模型在原 v2 网格上细化，保留既有体型，并非概念图毛发质感的逐像素复刻。
