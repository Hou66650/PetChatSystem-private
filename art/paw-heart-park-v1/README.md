# 爪心乐园 · 第一批视觉方案

本批只交付设计参考板、布局与效果图，不替换 `static/js/park-scene.js`、四座生活岛 GLB、网页入口或任何线上模型。所有图纸都是**概念方案，不是可交付模型，也不代表互动功能已完成**。

## 保留与统一

- 保留 `home-islands` 的 `sakura.glb`、`snow.glb`、`room.glb`、`camp.glb`，以及 `/den?pet=N` 和 `/park` 现有入口。
- 风格来自实际项目画面：樱花桥与花瓣、雪屋的分块木材与麻绳、雾林的石灰岩和林地、山岭的石塔与松林。
- 新乐园使用真实木材、麻绳、石材和草地的结构逻辑，配奶油黄、鼠尾草绿、森林绿、灰青和少量雾玫瑰。避免整岛塑料感，不把每件设施做成夸张动物脸。
- 可爱装饰只用于爪印铺装、花瓣或云朵边框、圆角构件和少量耳形上沿，不挡入口、落脚点或视线。

## 五岛与中央分区

`02-five-island-plan.png` 采用现有 `PetParkScene.positions`：四趾垫为 `(-15,0)`、`(-6,-10)`、`(6,-10)`、`(15,0)`，中央掌垫为 `(0,11)`。只调整掌垫内部，不重排生活岛，也不增加桥或额外岛屿。

中央掌垫分为：

1. **入口缓冲区**：南侧入口，先看全场再分流，视线直达中央草坪、休息区和隧道出口。
2. **互动草坪**：保留最大的连续留白，用于追逐、彩球和跳跃，不放大大型障碍。
3. **设施环**：钻行隧道、跳圈/跨杆、平衡木/小坡桥、猫爬架位于外围，互不串联成单一路径。
4. **安静休息区**：遮阴、饮水和低矮座椅，避开奔跑路线与设施出口。
5. **后勤边界**：玩具收纳、排水槽和溢水托盘在外侧低处，不占通道、落点或紧急退出路线。

## 六类设施设计

| 设施 | 真实结构 | 可爱细节 | 互动与退出 |
|---|---|---|---|
| 玩球草坪 | 低矮石边、外侧排水槽、独立彩球收纳 | 爪印指路、柔色哑光橡胶球 | 中央追逐弧完整，后勤不占急停区 |
| 钻行隧道 | 厚壳、独立支撑、防滑地面、可见另一端 | 仅上沿少量耳形轮廓 | 两端都可退出，后宠能看到前宠 |
| 低矮跳圈/跨杆 | 宽底座、圆角插接、跳跃净空 | 花瓣或云朵边框 | 高低尺度与绕行并存，落点不串线 |
| 平衡木/小坡桥 | 适中坡度、木板端面、板端连接件 | 浅嵌爪印踏点、圆角木构件 | 连续落点，两侧可下来与让行 |
| 猫咪攀爬与躲藏区 | 分层平台、抓挠柱、树洞、至少两条路线 | 叶片平台、非镜面树洞内壁 | 可爬可躲，也可从另一侧下来 |
| 遮阴休息与饮水区 | 花苞顶棚、抬高碗架、溢水托盘与外导 | 哑光顶棚、浅爪印铺装 | 可饮水可独处，入口直接看到 |

## 待确认问题

1. 中央掌垫是否严格保持首版约 18 m 展示宽度和现有轮廓？本方案默认保持，只改内部。
2. 体型验收是否按“幼年猫最小、成年德牧最大”覆盖全部成长阶段？本方案按全部猫狗体型预留绕行和跳点。
3. 玩球草坪、隧道、跳圈/跨杆、平衡木和猫爬架是否确认为可玩设施；入口与休息饮水区是否仅作景观和照料？后续不能用通用按钮动作冒充这些设施互动。
4. 多人同场仍以当前 12 位为上限吗？物理彩球、隧道和跳点的排队与碰撞规则需要按此人数进一步确认。
5. 样板区是否按“入口＋玩球草坪＋安静休息角”推进？确认后才制作入口之外的其余设施。
6. 材质是否全部使用项目内自建的木纹、绳纹、石纹和草皮贴图，不引入新的第三方纹理？本方案默认自建。
7. 光照是否沿用现有暖主光＋冷环境光的日景，夜景在完整模型后另行验收？本方案先只做日景。
8. 低、中、高精细度版本的预算是否优先保证 12 位高精度宠物同场？设施 LOD 不应以牺牲宠物轮廓和动作换取三角形额度。
