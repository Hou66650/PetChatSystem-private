# 双犬运动骨架 · v1.13.0

柴犬和哈士奇都保留原来的网格、材质、表情和 32 个动画片段，扩展到 45 个骨骼节点、35 个动画片段。

新增 12 个加权变形控制：前/后脊背、颈部细分、尾部细分、左右肩部、左右胯部、四只脚的脚趾。未增加模型表面细分；每顶点导出最多四个骨骼影响，适配当前 Three.js 蒙皮。GLB 各约 4.7 MB，继续只加载当前选中的宠物。

## 运动行为

- `motion_walk`：四拍慢走，周期 1.1 秒。
- `motion_trot`：对角肢小跑，周期 0.8 秒。
- `run`：前后肢错相跑动，周期约 0.667 秒。
- IK 只在 Blender 创作时使用，结果烘焙到变形骨骼；浏览器不逐帧计算 IK。
- 起步与制动使用平滑加速度；步态通过带滞回阈值的速度区间选择，播放速度根据支撑期步长校准。切换步态保留归一化周期，并使用已有动画混合。
- 大角度转向使用原有转身片段，行进速度受朝向夹角约束。近目标会减速，所有位置仍由原有导航校验。
- 「动作 → 跑一跑」选择一条可达路线；追玩具请求奔跑，叼回请求小跑。短路线或急弯可能达不到奔跑速度，这是减速保护的结果。
- 猫咪、德牧和旧模型回退仍使用走路，不会调用缺失动画。

## 文件与重建

- `qiuqiu.blend`、`xueqiu.blend`：可编辑骨架和动画源文件。
- `qiuqiu-run.png`、`xueqiu-run.png`：Blender 实际姿态渲染。
- `build-report.json`：骨骼数量、权重覆盖、创作时接地误差及资源大小。
- 项目根目录执行 `blender --background --python scripts/blender/build_dog_locomotion.py`。

## 验证

`node test/dog_locomotion.cjs` 检查旧动作保留、45 节点、35 片段、循环首尾连续、有限变换、接地误差、速度切换、加速度范围、转身优先、交互打断及旧模型回退。创作时踝关节 IK 最大目标误差小于 0.001 米；这不是运行时动态地形 IK 的承诺。另回归两岛导航、玩具寻回、表情、语音动作、按需加载、画质控制和宽高比。
