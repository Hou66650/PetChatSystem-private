# 雪球动作与表情 v1.9.0

基于 `static/models/petchat-snow-v1/xueqiu.glb` 保留哈士奇的蓝灰白毛色、蓝眼睛、项圈和原有 20 个动画。参照球球已有的表情设计及动作图纸，为雪球的头脸、耳根和长身比例重新设置控制区域与蒙皮，新增 8 根控制骨骼、双眼睑形变与舌头细节。腿部 IK 在 Blender 中烘焙，无浏览器运行时 IK 成本。

网页资产：`static/models/petchat-husky-v2/xueqiu.glb`，约 4.47 MB，32 组动画、33 根骨骼。原模型作为加载失败时的备用，只开放它实际具备的能力。继续沿用选中才加载和切换释放机制。

可编辑源文件：`xueqiu-v2.blend`。执行 `blender --background --python scripts/blender/build_husky_v2.py` 重建模型及全部 PNG 实渲。`neutral.png` 与其余 12 张动作图均为模型实际渲染，不是概念图。
